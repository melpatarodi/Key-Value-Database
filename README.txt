This program allows the user to store values in keys while using file persistence. The program uses unordered_map data for O(1) key lookups.

=== Instructions for running the program ===
You must open the project in terminal and then write these commands. 

1. chmod +x run.sh
2. ./run.sh

1 only has to be ran once during run.sh's lifetime. (Meaning if run.sh is deleted and recreated you must run it again)
2 is how you execute the program.

The database is saved to database.txt whenever the user chooses to save or exit the program.
